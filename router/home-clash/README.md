# Локальная интеграция полной Clash-подписки

Эти исходники сохранены из работающей интеграции с уже настроенными Podkop/sing-box, TPROXY и zapret2. **Это не универсальный установщик OpenWrt.** Установка на другую систему требует адаптации интерфейса, marks, очередей, путей, DNS, правил firewall и исходного генератора. Действующая подписка, YAML с реквизитами, API-secret, бинарник и резервные копии здесь отсутствуют.

| Файл | Назначение / установленный путь |
|---|---|
| `home-clash` | Управление и обновление: `/usr/sbin/home-clash` |
| `home-clash.init` | procd-служба `/etc/init.d/home-clash` |
| `normalize.awk` | Выделение политики подписки и локальные настройки DNS |
| `servers.awk` | Извлечение endpoint из поддерживаемого блочного YAML |
| `endpoints.sh` | Обновление узкого IPv4 nft-набора внешнего VPN |
| `bridge.jq` | Дополнительный фильтр поверх прежнего локального финального hook |
| `view.js` | LuCI `/www/luci-static/resources/view/home-clash.js` |
| `menu.json` | `/usr/share/luci/menu.d/luci-app-home-clash.json` |
| `acl.json` | `/usr/share/rpcd/acl.d/luci-app-home-clash.json` |

Вспомогательные awk/sh устанавливаются в `/etc/home-clash`. Нужны существующие curl,jq,dig,nft,gzip,awk,procd и проверенное ARM64-ядро Mihomo. В текущей установке сжатое ядро и кеши находятся в `/etc/home-clash/assets`, распаковка выполняется в `/tmp/home-clash`. Не скачивайте и не исполняйте бинарник без проверки происхождения и хеша.

Закрытые файлы создаются вне Git в `/etc/home-clash/private` с правами каталога700: `subscription.url`, `source.yaml`, `api-secret`, `selections.json`. Для импорта интерфейс записывает `new-url`, после успеха ссылка становится текущей. Секреты не передаются через аргументы curl и не включаются в публичные отчёты.

Локальная адаптация:

- `bridge.jq` в этой установке добавлен **после** существующего `vpn-final.jq`, а не вместо всего генератора.
- `home-routing-sync subscription` при включённом режиме вызывает новый updater, сохраняя прежнее расписание cron.
- `home-routing-api` читает контроллер Mihomo; `home-routing-status` показывает новый режим.
- Существующий init zapret301 принимает TCP-порты1–65535 при сохранении endpoint/mark-ограничения nft. Его Lua-стратегия не задаётся этими исходниками и должна быть отдельно испытана.
- Присутствуют cached `country.mmdb` и `category-ru.mrs`, необходимые именно проверенной подписке. Для другой подписки набор данных может отличаться.
- LuCI и исходники добавлены в локальный `sysupgrade.conf`; это сохранение файлов, а не гарантия совместимости с будущей прошивкой.

Исходники нормализатора и извлечения серверов ориентированы на проверенный блочный YAML, а не реализуют произвольный YAML-парсер. Неподдерживаемая/неработающая конфигурация должна оставлять прежнюю рабочую версию. Для будущих форматов подписки или новых типов правил нужна отдельная проверка.

Перед изменениями требуется закрытый backup текущих изменяемых файлов и независимый от SSH автоматический откат. В рабочей установке он был включён перед переключением и снят только после проверок. Не используйте архивные экспериментальные rollback-скрипты от другой схемы.

Подробности текущей архитектуры и фактических проверок: [настройка роутера](../../docs/router-setup.md), [подбор zapret2](../../docs/zapret-tuning-2026-10-27.md).
